# 使用者登出 — E2E 操作流程

> 頁面：任意已登入頁面

## 元素定義

> 登出相關元素（使用者選單、登出按鈕）見 _common.flow.md

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）

## 規則：登出時清除前端 Token

### 情境：登出成功

前置條件：
- 「使用者 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「使用者執行登出」
  1. 點擊使用者選單 → #user-menu
  2. 點擊「登出」按鈕 → #logout-button

預期結果：
- 「操作成功」→ 跳轉到 /login
- 「前端清除 Access Token」→ ⏭️ 跳過（內部狀態）
- 「前端清除 Refresh Token」→ ⏭️ 跳過（內部狀態）
- 「系統產生 "使用者已登出" 事件」→ ⏭️ 跳過（內部事件）

## 規則：未登入狀態執行登出無效果

### 情境：未登入時登出

⏭️ 整個情境跳過
原因：未登入狀態無法操作登出按鈕（需要先登入才能看到導航列）

## 規則：允許多裝置同時登入，登出僅影響當前裝置

### 情境：多裝置登入後單一裝置登出

⏭️ 整個情境跳過
原因：E2E 無法模擬多裝置同時登入的情境

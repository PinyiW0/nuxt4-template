# 使用者登出 — E2E 操作流程

> 頁面：登入頁（/login）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 登入頁面 | login-page | 頁面容器 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）

## 規則：登出時清除前端 Token

### 情境：登出成功

前置條件：
- 「使用者 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「使用者執行登出」
  1. 點擊使用者選單 → #user-menu
  2. 點擊「登出」按鈕 → #logout-button
  3. 等待跳轉到登入頁 → /login

預期結果：
- 「操作成功」→ 跳轉到 /login
- 「前端清除 Access Token」→ ⏭️ 跳過（內部狀態）
- 「前端清除 Refresh Token」→ ⏭️ 跳過（內部狀態）
- 「系統產生 "使用者已登出" 事件」→ ⏭️ 跳過（內部事件）

## 規則：未登入狀態執行登出無效果

### 情境：未登入時登出

⏭️ 整個情境跳過
原因：E2E 預設已登入進行測試，無法模擬未登入狀態登出

## 規則：允許多裝置同時登入，登出僅影響當前裝置

### 情境：多裝置登入後單一裝置登出

⏭️ 整個情境跳過
原因：E2E 無法測試多裝置場景

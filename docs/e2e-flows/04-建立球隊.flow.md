# 建立球隊 — E2E 操作流程

> 頁面：球隊管理（/teams）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 球隊頁面 | teams-page | 頁面容器 |
| 新增球隊按鈕 | team-create | 開啟新增彈窗 |
| 球隊列表 | team-list | 球隊表格 |
| 表單彈窗 | team-form-modal | 新增/編輯共用彈窗 |
| 球隊名稱欄位 | team-name | 名稱輸入框 |
| 儲存按鈕 | team-save | 彈窗送出按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）

## 規則：建立球隊只需提供名稱

### 情境：成功建立球隊

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練建立球隊名稱為 "紅龍隊"」
  1. 前往球隊管理頁 → /teams
  2. 點擊「新增球隊」按鈕 → #team-create
  3. 等待彈窗出現 → #team-form-modal
  4. 在「球隊名稱」欄位輸入 紅龍隊 → #team-name
  5. 點擊「建立」按鈕 → #team-save

預期結果：
- 「操作成功」→ 顯示成功提示
- 「系統產生 "球隊已建立" 事件」→ ⏭️ 跳過（內部事件）
- 「球隊 "紅龍隊" 的建立者為 "coach1"」→ #team-list 中「紅龍隊」那列包含「coach1」

## 規則：球隊名稱必須全系統唯一

### 情境：建立重複名稱的球隊

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練建立球隊名稱為 "藍鷹隊"」
  1. 前往球隊管理頁 → /teams
  2. 點擊「新增球隊」按鈕 → #team-create
  3. 等待彈窗出現 → #team-form-modal
  4. 在「球隊名稱」欄位輸入 藍鷹隊 → #team-name
  5. 點擊「建立」按鈕 → #team-save

預期結果：
- 「操作失敗」→ 顯示錯誤提示
- 「系統顯示 "球隊名稱已存在"」→ 文字「球隊名稱已存在」可見

## 規則：球隊名稱長度為 1-50 字元

### 情境：球隊名稱為空

⏭️ 整個情境跳過
原因：表單驗證由單元測試覆蓋

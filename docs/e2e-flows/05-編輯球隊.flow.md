# 編輯球隊 — E2E 操作流程

> 頁面：球隊管理（/teams）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 球隊頁面 | teams-page | 頁面容器 |
| 球隊列表 | team-list | 球隊表格 |
| 編輯按鈕 | team-edit | 列表中各列的編輯按鈕 |
| 表單彈窗 | team-form-modal | 新增/編輯共用彈窗 |
| 球隊名稱欄位 | team-name | 名稱輸入框 |
| 儲存按鈕 | team-save | 彈窗送出按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）

## 規則：編輯球隊時可修改名稱，需檢查全系統唯一性

### 情境：成功編輯球隊名稱

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練將球隊 "藍鷹隊" 的名稱修改為 "藍鷹猛禽隊"」
  1. 前往球隊管理頁 → /teams
  2. 在球隊列表中找到「藍鷹隊」那列 → #team-list
  3. 點擊該列的「編輯」按鈕 → #team-edit
  4. 等待彈窗出現 → #team-form-modal
  5. 清空「球隊名稱」欄位並輸入 藍鷹猛禽隊 → #team-name
  6. 點擊「儲存」按鈕 → #team-save

預期結果：
- 「操作成功」→ 顯示成功提示
- 「系統產生 "球隊已更新" 事件」→ ⏭️ 跳過（內部事件）

### 情境：編輯球隊名稱為已存在的名稱

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練將球隊 "藍鷹隊" 的名稱修改為 "紅龍隊"」
  1. 前往球隊管理頁 → /teams
  2. 在球隊列表中找到「藍鷹隊」那列 → #team-list

  4. 等待彈窗出現 → #team-form-modal
  5. 清空「球隊名稱」欄位並輸入 紅龍隊 → #team-name

預期結果：

## 規則：球隊名稱長度為 1-50 字元

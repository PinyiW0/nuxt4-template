# 刪除球隊 — E2E 操作流程

> 頁面：球隊管理（/teams）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 球隊頁面 | teams-page | 頁面容器 |
| 球隊列表 | team-list | 球隊表格 |
| 刪除按鈕 | team-delete | 刪除球隊按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「球隊 "藍鷹隊" 中有以下球員：」→ 不需操作（mock 資料已預設）

## 規則：刪除球隊採用軟刪除（標記 is_deleted = true）

### 情境：成功刪除球隊

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練刪除球隊 "藍鷹隊"」
  1. 前往球隊管理頁 → /teams
  2. 在球隊列表中找到「藍鷹隊」那列 → #team-list
  3. 點擊該列的「刪除」按鈕 → #team-delete
  4. 等待確認彈窗出現 → #confirm-modal
  5. 點擊「確認」按鈕 → #confirm-ok

預期結果：
- 「操作成功」→ 顯示成功提示「球隊已刪除」
- 「系統產生 "球隊已刪除" 事件」→ ⏭️ 跳過（內部事件）
- 「球隊 "藍鷹隊" 的狀態為 "deleted"」→ #team-list 不包含「藍鷹隊」

# 編輯球員 — E2E 操作流程

> 頁面：球員管理（/players）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 球員頁面 | players-page | 頁面容器 |
| 球員列表 | player-list | 球員表格 |
| 編輯按鈕 | player-edit | 開啟編輯彈窗 |
| 表單彈窗 | player-form-modal | 新增/編輯共用彈窗 |
| 背號欄位 | player-number | 背號輸入框 |
| 姓名欄位 | player-name | 姓名輸入框 |
| 身高欄位 | player-height | 身高輸入框 |
| 守備位置欄位 | player-position | 守備位置下拉選單 |
| 儲存按鈕 | player-save | 彈窗送出按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「球隊 "藍鷹隊" 中有以下球員：」→ 不需操作（mock 資料已預設）

## 規則：編輯球員可修改背號、姓名、身高、守備位置

### 情境：成功編輯球員資料

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練將球員 "王小明" 的身高修改為 178 公分」
  1. 前往球員管理頁 → /players
  2. 在球員列表中找到「王小明」那列 → #player-list
  3. 點擊該列的「編輯」按鈕 → #player-edit
  4. 等待彈窗出現 → #player-form-modal
  5. 清空並輸入 178 → #player-height
  6. 點擊「儲存」按鈕 → #player-save

預期結果：
- 「操作成功」→ 顯示成功提示「球員已更新」
- 「系統產生 "球員已更新" 事件」→ ⏭️ 跳過（內部事件）

# 刪除球員 — E2E 操作流程

> 頁面：球員管理（/players）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 球員頁面 | players-page | 頁面容器 |
| 球員列表 | player-list | 球員表格 |
| 刪除按鈕 | player-delete | 列表中各列的刪除按鈕 |

> 確認彈窗元素見 _common.flow.md

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「球隊 "藍鷹隊" 中有以下球員：」→ 不需操作（mock 資料已預設）

## 規則：刪除球員採用軟刪除（標記 is_deleted = true）

### 情境：成功刪除球員

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練刪除球員 "王小明"」
  1. 前往球員管理頁 → /players
  2. 在球員列表中找到「王小明」那列 → #player-list
  3. 點擊該列的「刪除」按鈕 → #player-delete
  4. 等待確認彈窗出現 → #confirm-modal
  5. 點擊「確認」按鈕 → #confirm-ok

預期結果：
- 「操作成功」→ 顯示成功提示
- 「系統產生 "球員已刪除" 事件」→ ⏭️ 跳過（內部事件）
- 「球員 "王小明" 的狀態為 "deleted"」→ ⏭️ 跳過（內部狀態）

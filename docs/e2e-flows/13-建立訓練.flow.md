# 建立訓練 — E2E 操作流程

> 頁面：訓練管理（/trainings）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 訓練頁面 | trainings-page | 頁面容器 |
| 新增訓練按鈕 | training-create | 開啟新增彈窗 |
| 訓練列表 | training-list | 訓練表格 |
| 表單彈窗 | training-form-modal | 新增訓練彈窗 |
| 日期欄位 | training-date | 訓練日期選擇器 |
| 受測選手欄位 | training-player | 受測選手下拉選單 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「球隊 "藍鷹隊" 中有以下球員：」→ 不需操作（mock 資料已預設）

## 規則：每次訓練只能指定一名受測選手

### 情境：成功建立訓練

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練建立訓練」
  1. 前往訓練管理頁 → /trainings
  2. 點擊「新增訓練」按鈕 → #training-create
  3. 等待彈窗出現 → #training-form-modal
  4. 在「日期」欄位輸入 2026-01-26 → #training-date
  5. 點擊「受測選手」下拉選單並選擇 王小明 → #training-player
  6. 點擊「建立」按鈕 → #training-save

預期結果：
- 「操作成功」→ 顯示成功提示
- 「系統產生 "訓練已建立" 事件」→ ⏭️ 跳過（內部事件）

### 情境：嘗試指定多名受測選手

⏭️ 整個情境跳過
原因：UI 為單選下拉選單，無法選取多名受測選手

## 規則：建立訓練時好球帶身高預設帶入受測選手身高，可手動調整

### 情境：好球帶身高預設帶入

⏭️ 整個情境跳過
原因：好球帶預設值為內部邏輯，由單元測試覆蓋

### 情境：手動調整好球帶身高

⏭️ 整個情境跳過
原因：好球帶調整在訓練詳情頁（Feature 20），此處僅建立訓練

## 規則：教練只能為自己球隊的球員建立訓練

### 情境：教練為自己球隊的球員建立訓練

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練為球員 "王小明" 建立訓練」→ （同上方「成功建立訓練」的操作步驟）

預期結果：
- 「操作成功」→ 顯示成功提示

### 情境：教練為他人球隊的球員建立訓練

原因：API 層已過濾，受測選手下拉選單只顯示自己球隊的球員，UI 無法觸發

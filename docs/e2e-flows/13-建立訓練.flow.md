# 建立訓練 — E2E 操作流程

> 頁面：訓練管理（/trainings）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 訓練頁面 | trainings-page | 頁面容器 |
| 訓練列表 | training-list | 訓練表格 |
| 新增訓練按鈕 | training-create | 開啟新增彈窗 |
| 表單彈窗 | training-form-modal | 新增訓練彈窗 |
| 日期欄位 | training-date | 日期輸入框 |
| 受測選手欄位 | training-player | 受測選手下拉選單 |
| 好球帶身高欄位 | training-strike-zone-height | 好球帶身高輸入框 |
| 儲存按鈕 | training-save | 彈窗送出按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「球隊 "藍鷹隊" 中有以下球員：」→ 不需操作（mock 資料已預設）

## 規則：每次訓練只能指定一名受測選手

### 情境：成功建立訓練

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練建立訓練：」
  1. 前往訓練管理頁 → /trainings
  2. 點擊「新增訓練」按鈕 → #training-create
  3. 等待彈窗出現 → #training-form-modal
  4. 在「日期」欄位輸入 2026-01-26 → #training-date
  5. 在「受測選手」欄位選擇 王小明 → #training-player
  6. 點擊「建立」按鈕 → #training-save

預期結果：
- 「操作成功」→ 顯示成功提示「訓練已建立」
- 「系統產生 "訓練已建立" 事件」→ ⏭️ 跳過（內部事件）

### 情境：嘗試指定多名受測選手

⏭️ 整個情境跳過
原因：UI 下拉選單只能選一個選手，無法觸發此情境

## 規則：建立訓練時好球帶身高預設帶入受測選手身高，可手動調整

### 情境：好球帶身高預設帶入

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練建立訓練並選擇受測選手 "王小明"」
  1. 前往訓練管理頁 → /trainings
  2. 點擊「新增訓練」按鈕 → #training-create
  3. 等待彈窗出現 → #training-form-modal
  4. 在「受測選手」欄位選擇 王小明 → #training-player

預期結果：
- 「操作成功」→ 顯示成功提示
- 「訓練的好球帶身高預設為 175 公分」→ #training-strike-zone-height 包含「175」

### 情境：手動調整好球帶身高

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練建立訓練並選擇受測選手 "王小明"，並將好球帶身高調整為 170 公分」
  1. 前往訓練管理頁 → /trainings
  2. 點擊「新增訓練」按鈕 → #training-create
  3. 等待彈窗出現 → #training-form-modal
  4. 在「日期」欄位輸入 2026-01-26 → #training-date
  5. 在「受測選手」欄位選擇 王小明 → #training-player
  6. 清空並輸入 170 → #training-strike-zone-height
  7. 點擊「建立」按鈕 → #training-save

預期結果：
- 「操作成功」→ 顯示成功提示「訓練已建立」
- 「訓練的好球帶身高為 170 公分」→ ⏭️ 跳過（內部狀態，需查詢 API 才能驗證實際儲存值）

操作步驟：

# 刪除訓練 — E2E 操作流程

> 頁面：訓練管理（/trainings）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 訓練頁面 | trainings-page | 頁面容器 |
| 訓練列表 | training-list | 訓練表格 |
| 刪除訓練按鈕 | training-delete | 刪除訓練按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「系統中有以下訓練：」→ 不需操作（mock 資料已預設）
- 「訓練 "T001" 有以下投球紀錄：」→ 不需操作（mock 資料已預設）

## 規則：刪除訓練採用軟刪除（標記 is_deleted = true）

### 情境：成功刪除訓練

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練刪除訓練 "T001"」
  1. 前往訓練管理頁 → /trainings
  2. 在訓練列表中找到「T001」那列 → #training-list
  3. 點擊該列的「刪除」按鈕 → #training-delete
  4. 等待確認彈窗出現 → #confirm-modal
  5. 點擊「確認」按鈕 → #confirm-ok

預期結果：
- 「操作成功」→ 顯示成功提示「訓練已刪除」
- 「系統產生 "訓練已刪除" 事件」→ ⏭️ 跳過（內部事件）
- 「訓練 "T001" 的狀態為 "deleted"」→ ⏭️ 跳過（內部狀態）

### 情境：刪除有投球紀錄的訓練

# 查看訓練紀錄 — E2E 操作流程

> 頁面：訓練詳情（/trainings/{id}）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 訓練詳情頁面 | training-detail-page | 頁面容器 |
| 訓練基本資訊 | training-info | 訓練基本資訊區域 |
| 投球清單 | pitch-list | 投球清單列表 |
| 投球清單行 | pitch-row | 投球清單行 |
| 即時統計區域 | training-stats | 即時統計區域 |
| 總投球數 | training-total-pitches | 總投球數顯示 |
| 好球數 | training-strike-count | 好球數顯示 |
| 壞球數 | training-ball-count | 壞球數顯示 |
| 好球率 | training-strike-rate | 好球率顯示 |
| 平均球速 | training-avg-velocity | 平均球速顯示 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球員：」→ 不需操作（mock 資料已預設）
- 「系統中有以下訓練：」→ 不需操作（mock 資料已預設）
- 「訓練 1 有以下投球紀錄：」→ 不需操作（mock 資料已預設）

## 規則：訓練紀錄頁顯示訓練基本資訊

### 情境：查看訓練基本資訊

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練查看訓練 1 的紀錄」
  1. 前往訓練詳情頁 → /trainings/1
  2. 等待頁面載入 → #training-detail-page

預期結果：
- 「操作成功」→ 顯示成功提示
- 「顯示訓練基本資訊：」→ #training-info 包含「2026-01-26」
- 「顯示訓練基本資訊：」→ #training-info 包含「藍鷹隊」
- 「顯示訓練基本資訊：」→ #training-info 包含「王小明」

## 規則：教練只能查看自己建立的訓練紀錄

### 情境：教練查看他人的訓練紀錄

⏭️ 整個情境跳過
原因：列表中不會顯示他人訓練，無法導航到他人的訓練詳情頁

# 查看單球儀表板 — E2E 操作流程

> 頁面：單球儀表板（/trainings/{id}/pitches/{pitchId}）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 單球儀表板頁面 | pitch-page | 頁面容器 |
| 九宮格視圖 | pitch-grid-view | 九宮格（好球帶）視圖 |
| 3D 軌跡視圖 | pitch-3d-view | 3D 入壘軌跡視圖 |
| 九宮格 Tab | pitch-tab-grid | 切換至九宮格視圖的 Tab |
| 3D 軌跡 Tab | pitch-tab-3d | 切換至 3D 軌跡視圖的 Tab |
| 球速標註 | pitch-velocity | 球速標註文字 |
| 落點標記 | pitch-location | 投球落點標記 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下訓練：」→ 不需操作（mock 資料已預設）
- 「訓練 1 有以下投球紀錄：」→ 不需操作（mock 資料已預設）

## 規則：單球儀表板預設顯示九宮格視圖

### 情境：開啟單球儀表板

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）
- 「教練正在查看訓練 1 的紀錄」→ 不需操作（直接導航）

操作步驟：
- 「教練點擊投球 1 查看詳情」
  1. 前往單球儀表板頁 → /trainings/1/pitches/1
  2. 等待頁面載入 → #pitch-page

預期結果：
- 「開啟單球儀表板」→ ⏭️ 跳過（查詢操作無提示，由頁面內容驗證）
- 「預設顯示九宮格視圖」→ #pitch-grid-view 包含「」

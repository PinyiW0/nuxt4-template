# 設定好球帶範圍 — E2E 操作流程

> 頁面：訓練詳情（/trainings/{id}）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 訓練詳情頁面 | training-detail-page | 頁面容器 |
| 好球帶編輯按鈕 | strike-zone-edit | 開啟好球帶設定彈窗 |
| 好球帶設定彈窗 | strike-zone-form-modal | 好球帶設定彈窗 |
| 好球帶上緣欄位 | strike-zone-upper | 好球帶上緣輸入框 |
| 好球帶下緣欄位 | strike-zone-lower | 好球帶下緣輸入框 |
| 好球帶儲存按鈕 | strike-zone-save | 好球帶儲存按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下訓練：」→ 不需操作（mock 資料已預設）
- 「訓練 "T001" 的好球帶設定：」→ 不需操作（mock 資料已預設）

## 規則：好球帶可調整上緣、下緣（寬度固定為本壘板寬度 43 公分）

### 情境：成功調整好球帶高度

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練將訓練 "T001" 的好球帶設定為：」
  1. 前往訓練詳情頁 → /trainings/T001
  2. 等待頁面載入 → #training-detail-page
  3. 點擊「好球帶設定」按鈕 → #strike-zone-edit
  4. 等待彈窗出現 → #strike-zone-form-modal
  5. 清空並輸入 130 → #strike-zone-upper
  6. 清空並輸入 55 → #strike-zone-lower
  7. 點擊「儲存」按鈕 → #strike-zone-save

預期結果：
- 「操作成功」→ 顯示成功提示
- 「系統產生 "好球帶範圍已更新" 事件」→ ⏭️ 跳過（內部事件）

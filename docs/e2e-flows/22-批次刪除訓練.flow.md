# 批次刪除訓練 — E2E 操作流程

> 頁面：歷史訓練（/trainings/history）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 歷史訓練頁面 | history-page | 頁面容器 |
| 歷史訓練列表 | history-list | 歷史訓練表格 |
| 歷史訓練列表行 | history-row | 歷史訓練列表行（帶 checkbox） |
| 批次刪除按鈕 | batch-delete-btn | 批次刪除按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下訓練：」→ 不需操作（mock 資料已預設）

## 規則：批次刪除訓練採用軟刪除

### 情境：成功批次刪除訓練

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練批次刪除訓練 "T001", "T002"」
  1. 前往歷史訓練頁 → /trainings/history
  2. 勾選「T001」那列的 checkbox → #history-row
  3. 勾選「T002」那列的 checkbox → #history-row
  4. 點擊「批次刪除」按鈕 → #batch-delete-btn
  5. 等待確認彈窗出現 → #confirm-modal
  6. 點擊「確認」按鈕 → #confirm-ok

預期結果：
- 「操作成功」→ 顯示成功提示「訓練已批次刪除」
- 「系統產生 "訓練已批次刪除" 事件」→ ⏭️ 跳過（內部事件）
- 「訓練 "T001" 的狀態為 "deleted"」→ ⏭️ 跳過（內部狀態）
- 「訓練 "T002" 的狀態為 "deleted"」→ ⏭️ 跳過（內部狀態）

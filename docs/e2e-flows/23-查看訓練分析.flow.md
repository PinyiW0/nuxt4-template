# 查看訓練分析 — E2E 操作流程

> 頁面：訓練分析（/trainings/{id}/analysis）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 訓練分析頁面 | training-analysis-page | 頁面容器 |
| 總投球數 | analysis-total-pitches | 總投球數顯示 |
| 好球數 | analysis-strike-count | 好球數顯示 |
| 壞球數 | analysis-ball-count | 壞球數顯示 |
| 好球率 | analysis-strike-rate | 好球率顯示 |
| 平均球速 | analysis-avg-velocity | 平均球速顯示 |
| 最快球速 | analysis-max-velocity | 最快球速顯示 |
| 最慢球速 | analysis-min-velocity | 最慢球速顯示 |
| 平均轉速 | analysis-avg-spin-rate | 平均轉速顯示 |
| 熱區圖 | analysis-heat-map | 落點熱區圖 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球員：」→ 不需操作（mock 資料已預設）
- 「系統中有以下訓練：」→ 不需操作（mock 資料已預設）
- 「訓練 1 有以下投球紀錄：」→ 不需操作（mock 資料已預設）

## 規則：訓練分析頁為統計彙總視圖，用於賽後分析

### 情境：查看訓練分析

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練查看訓練 1 的分析」
  1. 前往訓練分析頁 → /trainings/1/analysis
  2. 等待頁面載入 → #training-analysis-page

預期結果：
- 「操作成功」→ 顯示成功提示
- 「顯示訓練統計彙總」→ #analysis-total-pitches 包含「5」

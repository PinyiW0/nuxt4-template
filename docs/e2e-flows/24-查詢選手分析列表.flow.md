# 查詢選手分析列表 — E2E 操作流程

> 頁面：選手分析列表（/analysis）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 選手分析頁面 | analysis-page | 頁面容器 |
| 選手分析列表 | player-analysis-list | 選手分析表格 |
| 選手分析列表行 | player-analysis-row | 選手分析列表行 |
| 球隊篩選 | player-analysis-team-filter | 球隊篩選下拉選單 |
| 姓名搜尋 | player-analysis-search | 姓名搜尋輸入框 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球員：」→ 不需操作（mock 資料已預設）
- 「系統中有以下選手分析數據：」→ 不需操作（mock 資料已預設）

### 情境：教練查詢選手分析列表

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練查詢選手分析列表」
  1. 前往選手分析頁 → /analysis
  2. 等待頁面載入 → #analysis-page

- 「回傳以下選手分析：」→ #player-analysis-list 不包含「張三豐」

## 規則：支援依球隊篩選

### 情境：管理者篩選特定球隊的選手分析

前置條件：
- 「管理者 "admin" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「管理者查詢選手分析列表，篩選球隊 "藍鷹隊"」
  1. 前往選手分析頁 → /analysis
  2. 等待頁面載入 → #analysis-page
  3. 點擊球隊篩選下拉選單 → #player-analysis-team-filter
  4. 點擊「藍鷹隊」選項 → #player-analysis-team-filter

預期結果：
- 「只回傳藍鷹隊的選手分析（共 2 筆）」→ #player-analysis-list 包含「王小明」
- 「只回傳藍鷹隊的選手分析（共 2 筆）」→ #player-analysis-list 包含「李大華」
- 「只回傳藍鷹隊的選手分析（共 2 筆）」→ #player-analysis-list 不包含「張三豐」

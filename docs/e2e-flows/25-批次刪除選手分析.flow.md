# 批次刪除選手分析 — E2E 操作流程

> 頁面：選手分析列表（/analysis）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 選手分析頁面 | analysis-page | 頁面容器 |
| 選手分析列表 | player-analysis-list | 選手分析表格 |
| 選手分析列表行 | player-analysis-row | 選手分析列表行（帶 checkbox） |
| 批次刪除按鈕 | batch-delete-btn | 批次刪除按鈕 |

## 共用前置條件

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）
- 「系統中有以下球隊：」→ 不需操作（mock 資料已預設）
- 「球隊 "藍鷹隊" 中有以下球員：」→ 不需操作（mock 資料已預設）
- 「球員 "王小明" 有 5 筆訓練紀錄和 50 筆投球數據」→ 不需操作（mock 資料已預設）
- 「球員 "李大華" 有 3 筆訓練紀錄和 30 筆投球數據」→ 不需操作（mock 資料已預設）

## 規則：批次刪除選手分析只清除訓練與投球數據，保留選手基本資料

### 情境：成功批次刪除選手分析

前置條件：
- 「教練 "coach1" 已登入」→ （共用步驟，見 _common.flow.md）

操作步驟：
- 「教練批次刪除選手 "王小明", "李大華" 的分析資料」
  1. 前往選手分析頁 → /analysis
  2. 勾選「王小明」那列的 checkbox → #player-analysis-row
  3. 勾選「李大華」那列的 checkbox → #player-analysis-row
  4. 點擊「批次刪除」按鈕 → #batch-delete-btn
  5. 等待確認彈窗出現 → #confirm-modal
  6. 點擊「確認」按鈕 → #confirm-ok

預期結果：
- 「操作成功」→ 顯示成功提示「選手分析已批次刪除」
- 「系統產生 "選手分析已批次刪除" 事件」→ ⏭️ 跳過（內部事件）
- 「球員 "王小明" 的基本資料保留」→ ⏭️ 跳過（內部狀態）
- 「球員 "王小明" 的訓練紀錄被清除」→ ⏭️ 跳過（內部狀態）
- 「球員 "王小明" 的投球數據被清除」→ ⏭️ 跳過（內部狀態）
- 「球員 "李大華" 的基本資料保留」→ ⏭️ 跳過（內部狀態）
- 「球員 "李大華" 的訓練紀錄被清除」→ ⏭️ 跳過（內部狀態）
- 「球員 "李大華" 的投球數據被清除」→ ⏭️ 跳過（內部狀態）

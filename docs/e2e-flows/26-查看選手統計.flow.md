# 查看選手統計 — E2E 操作流程

> 頁面：選手統計（/analysis/{id}）

## 元素定義

| 元素 | testid | 說明 |
|------|--------|------|
| 選手統計頁面 | player-stats-page | 頁面容器 |
| 統計期間 | player-stats-period | 統計期間顯示 |
| 平均球速 | player-stats-avg-velocity | 平均球速顯示 |
| 平均轉速 | player-stats-avg-spin-rate | 平均轉速顯示 |
| 好球率 | player-stats-strike-rate | 好球率顯示 |
| 投球總數 | player-stats-total-pitches | 投球總數顯示 |
| 熱區圖 | player-stats-heat-map | 落點熱區圖 |

- 「系統中有以下使用者：」→ 不需操作（mock 資料已預設）

忠孝國中鷹眼系統平台 - 產品需求文件
## 1. 產品概述

### 1.1 背景

忠孝國中鷹眼系統平台旨在為校隊棒球訓練提供數位化、智能化的影像分析與投球數據管理解決方案。透過 AI 影像辨識技術，系統能自動捕捉投球軌跡、計算球速/轉速、判定好壞球，並提供電子好球帶記錄與長期統計分析，協助教練科學化訓練與選手表現追蹤。

### 1.2 產品目標

本期目標：
- ✅ 讓教練能在同一平台完成「訓練建立 → AI 系統啟動 → 即時投球數據檢視 → 歷史分析查詢」的完整閉環
- ✅ 提供九宮格落點圖、3D 入壘軌跡、電子好球帶記錄等多維度視覺化分析
- ✅ 支援球隊/球員資料管理與權限控管
- ✅ 提供選手長期表現追蹤（月平均統計、熱區圖）

非目標（本期不包含）：
- ❌ 賽事排程管理
- ❌ 多球場/多租戶架構
- ❌ 進階統計演算法（如預測模型、對戰分析）
- ❌ 行動裝置專屬 App（僅 Web 響應式）

## 2. 使用者與角色

### 2.1 角色定義

| 角色 | 描述 |
|------|------|
| **系統管理者** | 可管理所有帳號、球隊、訓練資料；具備最高權限 |
| **教練/一般使用者** | 可管理球隊/球員、建立/查詢訓練、查看分析報表 |

<br />

## 3. 核心使用流程

### 3.1 Flow 1: 訓練前置作業

```
登入系統 → 選擇/建立球隊 → 新增球員資料 → 建立訓練（選日期/球員/好球帶身高） → 啟動 AI 系統
```

### 3.2 Flow 2: 訓練中即時監控

```
訓練列表 → 點擊進入訓練紀錄頁 → 查看投球清單（即時更新） → 選擇單球 → 切換九宮格/3D 軌跡 → 調整好球帶參數
```

### 3.3 Flow 3: 賽後/歷史分析（訓練維度）

```
進入「影像數據分析」 → 訓練記錄查詢 → 篩選隊伍/日期 → 點擊訓練明細 → 查看電子好球帶記錄 → 開啟單球圖表彈窗
```

### 3.4 Flow 4: 選手長期表現追蹤

```
進入「影像數據分析」 → 選手紀錄查詢 → 選擇隊伍/關鍵字 → 點擊選手明細 → 查看月平均統計與熱區圖
```

## 4. 功能需求

### 🔹 Epic A: 登入/登出與權限控管

#### US-A1: 使用者登入
**身為** 系統使用者
**我想要** 用帳號/密碼登入
**以便** 進入鷹眼系統平台

#### US-A2: 使用者登出
**身為** 已登入使用者
**我想要** 登出並清除 token
**以便** 避免他人使用我的帳號

<br />

### 🔹 Epic B: 球隊/球員資料管理

#### US-B1: 球隊列表查詢與選擇
**身為** 管理者/教練
**我想要** 查詢並選擇球隊
**以便** 管理該隊球員

#### US-B2: 球隊維護（建立/編輯/刪除）
**身為** 管理者/教練
**我想要** 維護球隊資料
**以便** 確保名單正確

#### US-B3: 球員維護（列表/新增/編輯/刪除）
**身為** 管理者/教練
**我想要** 維護球員名單（背號、姓名、身高、守備位置）
**以便** 用於訓練與分析

**身為** 管理者/教練

**身為** 教練
**我想要** 啟動/關閉 AI 偵測系統
**以便** 控制現場系統狀態

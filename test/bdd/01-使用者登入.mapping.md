# 使用者登入 - 架構盤點

## Feature: 使用者登入

### Background (Feature-level)

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 系統中有以下使用者： | aggregate_given/ | Aggregate - User |

### Rule: 使用者以帳號密碼登入，成功後取得 JWT Token

#### Example: 登入成功

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 尚未登入 | aggregate_given/ | Aggregate - User |
| When | 使用者以帳號 "coach1" 密碼 "pass123" 登入 | commands/ | Command - login |
| Then | 操作成功 | common_then/ | Success |
| And | 系統回傳 Access Token（有效期 1-2 小時） | aggregate_then/ | Aggregate - Token |
| And | 系統回傳 Refresh Token（有效期 7 天） | aggregate_then/ | Aggregate - Token |
| And | 系統產生 "使用者已登入" 事件 | common_then/ | Event |

### Rule: 帳號或密碼錯誤時登入失敗

#### Example: 密碼錯誤

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 尚未登入 | aggregate_given/ | Aggregate - User |
| When | 使用者以帳號 "coach1" 密碼 "wrongpass" 登入 | commands/ | Command - login |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "帳號或密碼錯誤" | common_then/ | Message |

#### Example: 帳號不存在

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "unknown" 不存在 | aggregate_given/ | Aggregate - User |
| When | 使用者以帳號 "unknown" 密碼 "pass123" 登入 | commands/ | Command - login |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "帳號或密碼錯誤" | common_then/ | Message |

### Rule: 連續登入失敗 5 次後，帳號鎖定 15 分鐘

#### Example: 第 5 次登入失敗後帳號被鎖定

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 已連續登入失敗 4 次 | aggregate_given/ | Aggregate - User |
| When | 使用者以帳號 "coach1" 密碼 "wrongpass" 登入 | commands/ | Command - login |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "帳號已鎖定，請 15 分鐘後再試" | common_then/ | Message |
| And | 帳號 "coach1" 被鎖定 15 分鐘 | aggregate_then/ | Aggregate - User |

#### Example: 鎖定期間嘗試登入

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "locked1" 帳號已被鎖定 | aggregate_given/ | Aggregate - User |
| When | 使用者以帳號 "locked1" 密碼 "pass123" 登入 | commands/ | Command - login |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "帳號已鎖定，請稍後再試" | common_then/ | Message |

#### Example: 鎖定期滿後可重新登入

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "locked1" 帳號鎖定已過期 | aggregate_given/ | Aggregate - User |
| When | 使用者以帳號 "locked1" 密碼 "pass123" 登入 | commands/ | Command - login |
| Then | 操作成功 | common_then/ | Success |
| And | 登入失敗次數重置為 0 | aggregate_then/ | Aggregate - User |

### Rule: Access Token 過期後可用 Refresh Token 換取新 Token

#### Example: 使用 Refresh Token 換取新 Access Token

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 已登入 | commands/ | Command - login (前置條件) |
| And | Access Token 已過期 | aggregate_given/ | Aggregate - Token |
| And | Refresh Token 仍有效 | aggregate_given/ | Aggregate - Token |
| When | 使用者以 Refresh Token 請求新 Token | commands/ | Command - refreshToken |
| Then | 操作成功 | common_then/ | Success |
| And | 系統回傳新的 Access Token | aggregate_then/ | Aggregate - Token |

#### Example: Refresh Token 已過期

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 已登入 | commands/ | Command - login (前置條件) |
| And | Refresh Token 已過期 | aggregate_given/ | Aggregate - Token |
| When | 使用者以 Refresh Token 請求新 Token | commands/ | Command - refreshToken |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "請重新登入" | common_then/ | Message |

---

## 涉及的 Repository

- `userRepository`: User 資料存取（帳號、密碼、角色、鎖定狀態、失敗次數）

## 涉及的 Service

- `authService`: 認證業務邏輯（登入、Token 生成、Token 刷新、帳號鎖定）

## 需要新增的 Step Definitions

| 目錄 | 檔案 | 步驟 |
|------|------|------|
| aggregate_given/ | user.ts | 系統中有以下使用者：、使用者 {string} 尚未登入、使用者 {string} 不存在、使用者 {string} 已連續登入失敗 {int} 次、使用者 {string} 帳號已被鎖定、使用者 {string} 帳號鎖定已過期 |
| aggregate_given/ | token.ts | Access Token 已過期、Refresh Token 仍有效、Refresh Token 已過期 |
| commands/ | auth.ts | 使用者以帳號 {string} 密碼 {string} 登入、使用者 {string} 已登入、使用者以 Refresh Token 請求新 Token |
| common_then/ | index.ts | 操作成功、操作失敗、系統顯示 {string}、系統產生 {string} 事件 |
| aggregate_then/ | auth.ts | 系統回傳 Access Token（有效期 1-2 小時）、系統回傳 Refresh Token（有效期 7 天）、帳號 {string} 被鎖定 15 分鐘、登入失敗次數重置為 0、系統回傳新的 Access Token |

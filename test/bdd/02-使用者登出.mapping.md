# 使用者登出 - 架構盤點

## Feature: 使用者登出

### Background

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 系統中有以下使用者： | aggregate_given/ | Aggregate - User |

### Rule: 登出時清除前端 Token

#### Example: 登出成功

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 已登入 | commands/ | Command - login |
| When | 使用者執行登出 | commands/ | Command - logout |
| Then | 操作成功 | common_then/ | Success |
| And | 前端清除 Access Token | aggregate_then/ | Aggregate - Token |
| And | 前端清除 Refresh Token | aggregate_then/ | Aggregate - Token |
| And | 系統產生 "使用者已登出" 事件 | common_then/ | Event |

### Rule: 未登入狀態執行登出無效果

#### Example: 未登入時登出

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 尚未登入 | aggregate_given/ | Aggregate - User |
| When | 使用者執行登出 | commands/ | Command - logout |
| Then | 操作成功 | common_then/ | Success |
| And | 無任何狀態變更 | common_then/ | NoChange |

### Rule: 允許多裝置同時登入，登出僅影響當前裝置

#### Example: 多裝置登入後單一裝置登出

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 使用者 "coach1" 已在裝置 A 登入 | aggregate_given/ | Aggregate - DeviceSession |
| And | 使用者 "coach1" 已在裝置 B 登入 | aggregate_given/ | Aggregate - DeviceSession |
| When | 使用者在裝置 A 執行登出 | commands/ | Command - deviceLogout |
| Then | 裝置 A 的 Token 已清除 | aggregate_then/ | Aggregate - DeviceSession |
| And | 裝置 B 的 Token 仍有效 | aggregate_then/ | Aggregate - DeviceSession |

### 涉及的 Repository

- `userRepository`: User 資料存取
- _(device sessions stored in authService)_

### 涉及的 Service

- `authService`: 認證業務邏輯（含登出、裝置管理）

### 需要新增的 Step Definitions

| 目錄 | 檔案 | 步驟 |
|------|------|------|
| commands/ | auth.ts | 使用者執行登出 |
| aggregate_then/ | auth.ts | 前端清除 Access Token、前端清除 Refresh Token |
| common_then/ | index.ts | 無任何狀態變更 |
| aggregate_given/ | user.ts | 使用者 {string} 已在裝置 A 登入、使用者 {string} 已在裝置 B 登入 |
| commands/ | auth.ts | 使用者在裝置 A 執行登出 |
| aggregate_then/ | auth.ts | 裝置 A 的 Token 已清除、裝置 B 的 Token 仍有效 |

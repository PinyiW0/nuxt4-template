# 查詢球隊列表 - 架構盤點

## Feature: 查詢球隊列表

### Background

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 系統中有以下使用者： | aggregate_given/ | Aggregate - User |
| And | 系統中有以下球隊： | aggregate_given/ | Aggregate - Team |

### Rule: 教練只能查詢自己建立的球隊

#### Example: 教練查詢球隊列表

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球隊列表 | query/ | Query - getTeams |
| Then | 操作成功 | common_then/ | Success |
| And | 回傳以下球隊： | readmodel_then/ | ReadModel - TeamList |

### Rule: 管理者可查詢所有球隊

#### Example: 管理者查詢球隊列表

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者查詢球隊列表 | query/ | Query - getTeams |
| Then | 操作成功 | common_then/ | Success |
| And | 回傳所有 active 狀態的球隊（共 3 筆） | readmodel_then/ | ReadModel - TeamList |

### Rule: 列表依建立時間倒序排列

#### Example: 球隊列表排序

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球隊列表 | query/ | Query - getTeams |
| Then | 第一筆為 "紅龍隊"（較新建立） | readmodel_then/ | ReadModel - TeamList |
| And | 第二筆為 "藍鷹隊"（較早建立） | readmodel_then/ | ReadModel - TeamList |

### Rule: 列表回傳欄位包含 ID、名稱、球員數量、建立時間、建立者

#### Example: 確認回傳欄位

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球隊列表 | query/ | Query - getTeams |
| Then | 每筆資料包含以下欄位： | readmodel_then/ | ReadModel - TeamList |

### Rule: 支援分頁查詢

#### Example: 使用預設分頁

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球隊列表（未指定分頁參數） | query/ | Query - getTeams |
| Then | 回傳第 1 頁 | readmodel_then/ | ReadModel - Pagination |
| And | 每頁筆數為 20 | readmodel_then/ | ReadModel - Pagination |

#### Example: 指定每頁筆數

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者查詢球隊列表，每頁 10 筆 | query/ | Query - getTeams |
| Then | 每頁筆數為 10 | readmodel_then/ | ReadModel - Pagination |

### Rule: 已刪除的球隊不顯示在列表中

#### Example: 列表不包含已刪除球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者查詢球隊列表 | query/ | Query - getTeams |
| Then | 結果不包含 "黑豹隊"（已刪除） | readmodel_then/ | ReadModel - TeamList |

### 涉及的 Repository

- `userRepository`: User 資料存取
- `teamRepository`: Team 資料存取

### 涉及的 Service

- `authService`: 認證業務邏輯
- `teamService`: 球隊業務邏輯

### 需要新增的 Step Definitions

| 目錄 | 檔案 | 步驟 |
|------|------|------|
| aggregate_given/ | team.ts | 系統中有以下球隊： |
| commands/ | auth.ts | 教練 {string} 已登入、管理者 {string} 已登入 |
| query/ | team.ts | 教練查詢球隊列表、管理者查詢球隊列表、教練查詢球隊列表（未指定分頁參數）、管理者查詢球隊列表，每頁 {int} 筆 |
| readmodel_then/ | team.ts | 回傳以下球隊：、回傳所有 active 狀態的球隊（共 {int} 筆）、第一筆為 {string}（較新建立）、第二筆為 {string}（較早建立）、每筆資料包含以下欄位：、回傳第 {int} 頁、每頁筆數為 {int}、結果不包含 {string}（已刪除） |

# 建立球隊 - 架構盤點

## Feature: 建立球隊

### Background

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 系統中有以下使用者： | aggregate_given/ | Aggregate - User |
| And | 系統中有以下球隊： | aggregate_given/ | Aggregate - Team |

### Rule: 建立球隊只需提供名稱

#### Example: 成功建立球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練建立球隊名稱為 "紅龍隊" | commands/ | Command - createTeam |
| Then | 操作成功 | common_then/ | Success |
| And | 系統產生 "球隊已建立" 事件 | common_then/ | Event |
| And | 球隊 "紅龍隊" 的建立者為 "coach1" | aggregate_then/ | Aggregate - Team |

### Rule: 球隊名稱必須全系統唯一

#### Example: 建立重複名稱的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練建立球隊名稱為 "藍鷹隊" | commands/ | Command - createTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "球隊名稱已存在" | common_then/ | Message |

### Rule: 球隊名稱長度為 1-50 字元

#### Example: 球隊名稱為空

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練建立球隊名稱為 "" | commands/ | Command - createTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "球隊名稱不可為空" | common_then/ | Message |

### Rule: 教練只能建立自己的球隊，管理者可建立任何球隊

#### Example: 教練建立球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練建立球隊名稱為 "白虎隊" | commands/ | Command - createTeam |
| Then | 操作成功 | common_then/ | Success |
| And | 球隊 "白虎隊" 的建立者為 "coach1" | aggregate_then/ | Aggregate - Team |

### 涉及的 Repository

- `userRepository`: User 資料存取
- `teamRepository`: Team 資料存取

### 涉及的 Service

- `authService`: 認證業務邏輯
- `teamService`: 球隊業務邏輯

### 需要新增的 Step Definitions

| 目錄 | 檔案 | 步驟 |
|------|------|------|
| commands/ | team.ts | 教練建立球隊名稱為 {string} |
| aggregate_then/ | team.ts | 球隊 {string} 的建立者為 {string} |

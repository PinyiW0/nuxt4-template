# 編輯球隊 - 架構盤點

## Feature: 編輯球隊

### Background

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 系統中有以下使用者： | aggregate_given/ | Aggregate - User |
| And | 系統中有以下球隊： | aggregate_given/ | Aggregate - Team |

### Rule: 編輯球隊時可修改名稱，需檢查全系統唯一性

#### Example: 成功編輯球隊名稱

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練將球隊 "藍鷹隊" 的名稱修改為 "藍鷹猛禽隊" | commands/ | Command - updateTeam |
| Then | 操作成功 | common_then/ | Success |
| And | 系統產生 "球隊已更新" 事件 | common_then/ | Event |

#### Example: 編輯球隊名稱為已存在的名稱

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練將球隊 "藍鷹隊" 的名稱修改為 "紅龍隊" | commands/ | Command - updateTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "球隊名稱已存在" | common_then/ | Message |

### Rule: 球隊名稱長度為 1-50 字元

#### Example: 編輯球隊名稱為空

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練將球隊 "藍鷹隊" 的名稱修改為 "" | commands/ | Command - updateTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "球隊名稱不可為空" | common_then/ | Message |

### Rule: 教練只能編輯自己建立或被指派的球隊

#### Example: 教練編輯自己的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練將球隊 "藍鷹隊" 的名稱修改為 "藍鷹猛禽隊" | commands/ | Command - updateTeam |
| Then | 操作成功 | common_then/ | Success |

#### Example: 教練編輯他人的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練將球隊 "紅龍隊" 的名稱修改為 "紅龍火焰隊" | commands/ | Command - updateTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "無權限操作此球隊" | common_then/ | Message |

### Rule: 管理者可編輯所有球隊

#### Example: 管理者編輯任意球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者將球隊 "紅龍隊" 的名稱修改為 "紅龍火焰隊" | commands/ | Command - updateTeam |
| Then | 操作成功 | common_then/ | Success |

### Rule: 已刪除的球隊不可編輯

#### Example: 編輯已刪除的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 球隊 "藍鷹隊" 已被刪除 | aggregate_given/ | Aggregate - Team |
| And | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者將球隊 "藍鷹隊" 的名稱修改為 "藍鷹猛禽隊" | commands/ | Command - updateTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "球隊不存在或已刪除" | common_then/ | Message |

### 涉及的 Repository

- `userRepository`: User 資料存取
- `teamRepository`: Team 資料存取

### 涉及的 Service

- `authService`: 認證業務邏輯
- `teamService`: 球隊業務邏輯

### 需要新增的 Step Definitions

| 目錄 | 檔案 | 步驟 |
|------|------|------|
| commands/ | team.ts | 教練將球隊 {string} 的名稱修改為 {string}、管理者將球隊 {string} 的名稱修改為 {string} |
| aggregate_given/ | team.ts | 球隊 {string} 已被刪除 |

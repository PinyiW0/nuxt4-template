# 刪除球隊 - 架構盤點

## Feature: 刪除球隊

### Background

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 系統中有以下使用者： | aggregate_given/ | Aggregate - User |
| And | 系統中有以下球隊： | aggregate_given/ | Aggregate - Team |
| And | 球隊 "藍鷹隊" 中有以下球員： | aggregate_given/ | Aggregate - Player |

### Rule: 刪除球隊採用軟刪除（標記 is_deleted = true）

#### Example: 成功刪除球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練刪除球隊 "藍鷹隊" | commands/ | Command - deleteTeam |
| Then | 操作成功 | common_then/ | Success |
| And | 系統產生 "球隊已刪除" 事件 | common_then/ | Event |
| And | 球隊 "藍鷹隊" 的狀態為 "deleted" | aggregate_then/ | Aggregate - Team |

### Rule: 刪除球隊時連帶軟刪除所有關聯球員

#### Example: 刪除有球員的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練刪除球隊 "藍鷹隊" | commands/ | Command - deleteTeam |
| Then | 操作成功 | common_then/ | Success |
| And | 球隊 "藍鷹隊" 的狀態為 "deleted" | aggregate_then/ | Aggregate - Team |
| And | 球員 "王小明" 的狀態為 "deleted" | aggregate_then/ | Aggregate - Player |
| And | 球員 "李大華" 的狀態為 "deleted" | aggregate_then/ | Aggregate - Player |

### Rule: 教練只能刪除自己建立或被指派的球隊

#### Example: 教練刪除自己的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練刪除球隊 "藍鷹隊" | commands/ | Command - deleteTeam |
| Then | 操作成功 | common_then/ | Success |

#### Example: 教練刪除他人的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練刪除球隊 "紅龍隊" | commands/ | Command - deleteTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "無權限操作此球隊" | common_then/ | Message |

### Rule: 管理者可刪除所有球隊

#### Example: 管理者刪除任意球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者刪除球隊 "紅龍隊" | commands/ | Command - deleteTeam |
| Then | 操作成功 | common_then/ | Success |

### Rule: 已刪除的球隊不可再次刪除

#### Example: 重複刪除已刪除的球隊

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 球隊 "藍鷹隊" 已被刪除 | aggregate_given/ | Aggregate - Team |
| And | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者刪除球隊 "藍鷹隊" | commands/ | Command - deleteTeam |
| Then | 操作失敗 | common_then/ | Failure |
| And | 系統顯示 "球隊不存在或已刪除" | common_then/ | Message |

### 涉及的 Repository

- `userRepository`: User 資料存取
- `teamRepository`: Team 資料存取
- `playerRepository`: Player 資料存取（新增）

### 涉及的 Service

- `authService`: 認證業務邏輯
- `teamService`: 球隊業務邏輯（需新增 deleteTeam 方法）

### 需要新增的 Step Definitions

| 目錄 | 檔案 | 步驟 |
|------|------|------|
| aggregate_given/ | player.ts | 球隊 {string} 中有以下球員： |
| commands/ | team.ts | 教練刪除球隊 {string}、管理者刪除球隊 {string} |
| aggregate_then/ | team.ts | 球隊 {string} 的狀態為 {string} |
| aggregate_then/ | player.ts | 球員 {string} 的狀態為 {string} |

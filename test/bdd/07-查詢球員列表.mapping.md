# 查詢球員列表 - 架構盤點

## Feature: 查詢球員列表

### Background

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 系統中有以下使用者： | aggregate_given/ | Aggregate - User |
| And | 系統中有以下球隊： | aggregate_given/ | Aggregate - Team |
| And | 系統中有以下球員： | aggregate_given/ | Aggregate - Player |

### Rule: 教練只能查詢自己球隊的球員

#### Example: 教練查詢球員列表

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球員列表 | query/ | Query - getPlayers |
| Then | 操作成功 | common_then/ | Success |
| And | 回傳以下球員： | readmodel_then/ | ReadModel - Player |

### Rule: 管理者可查詢所有球員

#### Example: 管理者查詢球員列表

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者查詢球員列表 | query/ | Query - getPlayers |
| Then | 操作成功 | common_then/ | Success |
| And | 回傳所有 active 狀態的球員（共 3 筆） | readmodel_then/ | ReadModel - Player |

### Rule: 支援依球隊篩選

#### Example: 管理者篩選特定球隊的球員

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 管理者 "admin" 已登入 | commands/ | Command - login |
| When | 管理者查詢球員列表，篩選球隊 "藍鷹隊" | query/ | Query - getPlayers |
| Then | 只回傳藍鷹隊的球員（共 2 筆） | readmodel_then/ | ReadModel - Player |

### Rule: 列表依建立時間倒序排列（最新在前）

#### Example: 球員列表排序

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球員列表 | query/ | Query - getPlayers |
| Then | 第一筆為 "李大華"（較新建立） | readmodel_then/ | ReadModel (共用) |
| And | 第二筆為 "王小明"（較早建立） | readmodel_then/ | ReadModel (共用) |

### Rule: 列表回傳欄位包含 ID、背號、姓名、身高、守備位置、所屬球隊、建立時間、排序順位

#### Example: 確認回傳欄位

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球員列表 | query/ | Query - getPlayers |
| Then | 每筆資料包含以下欄位： | readmodel_then/ | ReadModel (共用) |

### Rule: 支援分頁查詢，預設每頁 20 筆，可選 10/20/50 筆

#### Example: 使用預設分頁

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球員列表（未指定分頁參數） | query/ | Query - getPlayers |
| Then | 回傳第 1 頁 | readmodel_then/ | ReadModel (共用) |
| And | 每頁筆數為 20 | readmodel_then/ | ReadModel (共用) |

### Rule: 已刪除的球員不顯示在列表中

#### Example: 列表不包含已刪除球員

| Step | Gherkin | 目錄 | 事件風暴部位 |
|------|---------|------|-------------|
| Given | 教練 "coach1" 已登入 | commands/ | Command - login |
| When | 教練查詢球員列表 | query/ | Query - getPlayers |
| Then | 結果不包含 "陳小強"（已刪除） | readmodel_then/ | ReadModel (共用) |

### 涉及的 Repository

- `userRepository`: User 資料存取
- `teamRepository`: Team 資料存取
- `playerRepository`: Player 資料存取

### 涉及的 Service

- `authService`: 認證
- `playerService`: 球員查詢（新增）

### 需要新增的 Step Definitions

| 目錄 | 檔案 | 步驟 |
|------|------|------|
| aggregate_given/ | player.ts | 系統中有以下球員： |
| query/ | player.ts | 教練查詢球員列表、管理者查詢球員列表、管理者查詢球員列表篩選球隊、教練查詢球員列表未指定分頁 |
| readmodel_then/ | player.ts | 回傳以下球員：、回傳所有 active 狀態的球員（共 N 筆）、只回傳藍鷹隊的球員（共 N 筆） |

### 可共用的 Step Definitions（已存在於 readmodel_then/team.ts）

- 第一筆為 {string}（較新建立）
- 第二筆為 {string}（較早建立）
- 每筆資料包含以下欄位：（需擴充 fieldMapping）
- 回傳第 {int} 頁
- 每頁筆數為 {int}
- 結果不包含 {string}（已刪除）
